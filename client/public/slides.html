Overview

What is PocketRoster?

  • A personal football roster tracker where each user owns their own teams and players.
  • Visitors must log in — all content is private and scoped to the account.
  • Supports multiple users, each with isolated data and full admin privileges over their own content.
  • Designed around the Hall of Fame concept — track legendary rosters from any era or game.
  • Works with real data or game saves (e.g. CFB 25, Madden).

Security & Access

Auth & Roles

  • Session-based auth using express-session and a secure session secret.
  • Every user gets a private, isolated workspace — teams, players, leagues.
  • All add / edit / delete controls are hidden from unauthenticated visitors.
  • API routes protected by requireAuth middleware on every mutation.
  • League and player pages redirect to login if not authenticated.
✓ Logged-in User
Full CRUD on own teams, players, stats, coaches, and league logos.
✗ Visitor
Sees only the Dashboard login prompt. No content visible without an account.
